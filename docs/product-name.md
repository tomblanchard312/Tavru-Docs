# Tavru Docs product name

The public name is **Tavru Docs**. Earlier public names, in order, were Nisaba, DraftHearth and Qanloom. The Qanloom name was in use from 2026-10-30 until the Tavru suite rename.

Window titles, About, help and the writing surface use Tavru Docs. The GitHub repository is `tomblanchard312/Tavru-Docs`.

These identifiers are unchanged:

- Cargo packages stay on the WordCraft names (`wordcraft`, `wordcraft-cli`).
- Installed executables stay `nisaba` and `nisaba-cli`.
- Settings and recovery stay `nisaba` / `Nisaba`.
- Application id stays `io.github.tomblanchard312.Nisaba`.
- `crates/brand` still publishes the homepage `https://github.com/tomblanchard312/Qanloom`. GitHub redirects that name; the constant has not been updated.
- Icon filename `nisaba-logo.png` and the existing upgrade identifiers stay.

Saved documents and Oqelith model data are not moved. Original upstream copyrights, licences and attribution stay in NOTICE and ATTRIBUTION.md.
